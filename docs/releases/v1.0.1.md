# dsh-restart 1.0.1

修正 1.0.0 文档里一处**会让人装不上插件**的错误说法。插件代码本身一字未改。

## 本次更新

- **删掉「安装不需要 git」这句错话。** 1.0.0 的 README 与 PACKAGING 都写着「pnpm 解析
  `github:owner/repo` 时直接下载 codeload 的源码 tarball，不跑 `git clone`」，据此推荐的安装命令是
  `add github:csuwzw/dsh-restart`。**实测不成立**：在没有任何 git 的 Windows 上，这条命令必然失败。

  实测命令与输出（桌面版 CLI，空 profile，本机 `Get-Command git` 为空）：

  ```
  dsh: initialized profile gh-test at C:\Users\Richard\.dsh\profiles\gh-test
  [ERROR] Command failed with exit code 1: git ls-remote "https://github.com/csuwzw/dsh-restart.git" HEAD "HEAD^{}"
  'git' 不是内部或外部命令，也不是可运行的程序
  ```

  pnpm 对**任何** GitHub 简写（裸 `github:o/r`、`#main`、`#v1.0.0`）都会先跑 `git ls-remote` 解析
  ref，所以「不需要 git」只对两种写法成立：commit sha 形式 `github:o/r#<40 位 sha>`，以及直接的
  codeload tarball URL。原先那句错的来源是 dshmarket 的 `lib/accelerate.js`——那里确实写着 pnpm 不
  跑 `git clone`（`accelerate.js:5-8`），但它紧接着在 `accelerate.js:20-33` 把裸 `github:` 重写成
  `github:o/r#<sha>` 来绕开 `ls-remote`，而那条重写只在市场自己的安装通道里生效。看到前一句就下结论，
  漏掉了后一句。

- **安装命令改用 codeload tarball URL。** 四处文档（README、README_EN、PACKAGING、docs/releases/v1.0.0.md）
  的命令统一改成：

  ```
  plugin --profile desktop add https://codeload.github.com/csuwzw/dsh-restart/tar.gz/refs/tags/v1.0.1
  ```

  这个地址就是一个普通压缩包，不经过 git。想固定版本用 `refs/tags/<tag>`，想跟最新用 `refs/heads/main`
  （代价是版本不可复现）。

- **补上实测矩阵。** README 与 PACKAGING 新增一张五种写法的对照表，都是本机实测结果：

  | 写法 | 结果 |
  | --- | --- |
  | `github:csuwzw/dsh-restart` | 失败，`git ls-remote` 找不到 git |
  | `github:csuwzw/dsh-restart#main` / `#v1.0.0` | 失败，同上 |
  | `github:csuwzw/dsh-restart#87a3945764a30d07298b627a93eefdcc56aee1bb` | 成功 |
  | `https://codeload.github.com/csuwzw/dsh-restart/tar.gz/refs/tags/v1.0.0` | 成功 |
  | `https://codeload.github.com/csuwzw/dsh-restart/tar.gz/refs/heads/main` | 成功 |

  顺带确认了 tag 本身没问题：`codeload .../refs/tags/v1.0.0` 返回 200、git 协议 advertisement 里
  有 `refs/tags/v1.0.0`，所以 `#v1.0.0` 的失败纯粹是缺 git，不是 tag 不存在。

## 安装

```
set ELECTRON_RUN_AS_NODE=1
"C:\D\software\DeepSeek Harness\DeepSeek Harness.exe" --expose-internals ^
  "C:\D\software\DeepSeek Harness\resources\app.asar\dsh\node_modules\@deepseek-ai\dsh-desktop-host\lib\cli.js" ^
  plugin --profile desktop add https://codeload.github.com/csuwzw/dsh-restart/tar.gz/refs/tags/v1.0.1
```

把路径换成自己的安装目录。其余安装方式（应用内插件管理器、手工放置、离线 tgz）见
[README](../../README.md#安装)。

**首次安装必须手动重启一次 DSH**——按钮要等重启后才存在。之后就用按钮本身。

## 升级与重启

从 1.0.0 升上来只需重新执行上面的安装命令，把 tag 换成 `v1.0.1`。这次改动全在文档里，`index.js`、
`client.js`、`restart.ps1` 与 1.0.0 逐字节相同（下面「验收」一节有比对结果），所以升级后行为不变，
重启与否只影响你看到的文档。

## 回退

回到 1.0.0：

```
plugin --profile desktop add https://codeload.github.com/csuwzw/dsh-restart/tar.gz/refs/tags/v1.0.0
```

或者移除 `dsh.profile.bundles` 里的 `dsh-restart`、从 `dependencies` 移除同名条目、删除
`node_modules/dsh-restart/`，然后重启应用一次。

  桌面版 Host 固定以 `--port 0` 启动，端口一直由系统分配（见 [1.0.0 验收记录第七节](../verification/2026-10-17-v1.0.0.md)）。

- **`github:` 简写依赖 git 这件事没有做代码层面的规避。** 本插件不改 pnpm 行为，只在文档里给出可用写法。
